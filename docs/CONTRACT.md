# Scope implementation contract

All JSON fields use camelCase. The local engine is the single source of truth.

## Core Rust public API (scope_core)

- `Engine::open(data_dir: impl AsRef<Path>) -> anyhow::Result<Engine>` (Clone)
- `engine.list_sessions() -> Result<Vec<Session>>`
- `engine.create_session(name: String, source: String) -> Result<Session>`
- `engine.list_exchanges(session_id: &str, query: Option<&str>, limit: usize, offset: usize) -> Result<Vec<Exchange>>`
- `engine.get_exchange(id: &str) -> Result<Exchange>`
- `engine.analysis(session_id: &str) -> Result<serde_json::Value>`
- `engine.export_har(session_id: &str) -> Result<serde_json::Value>`
- `engine.import_har(har: serde_json::Value, name: String) -> Result<Session>`
- `engine.export_session(session_id: &str) -> Result<serde_json::Value>`
- `engine.import_session(value: serde_json::Value) -> Result<Session>`
- `engine.ca_cert_path() -> PathBuf`
- `engine.start_proxy(session_id: String, port: u16) -> async Result<ProxyStatus>`
- `engine.stop_proxy() -> async Result<()>`
- `engine.proxy_status() -> ProxyStatus`
- `engine.set_breakpoints(request: bool, response: bool)`
- `engine.pending() -> Vec<PendingExchange>`
- `engine.resolve_breakpoint(id: &str, edit: EditMessage) -> Result<()>`
- `engine.has_pause_rule_for(method: &str, url: &str) -> bool` (point-in-time rule preflight)
- `engine.replay(id: &str, edit: Option<EditMessage>) -> async Result<Exchange>`
- `engine.compare_sessions(left: &str, right: &str) -> Result<serde_json::Value>`

Session { id, name, source, createdAt: i64 milliseconds, exchangeCount: i64, revision: i64 }
Header = { name: String, value: String } (array preserves repeated headers)
Exchange { id, sessionId, method, url, status: Option<u16>, requestHeaders: Vec<Header>, responseHeaders: Vec<Header>, requestBody: String, responseBody: String, requestBodyBase64: bool, responseBodyBase64: bool, startedAt: i64, durationMs: i64, requestBytes: i64, responseBytes: i64, error: Option<String>, edited: bool, originalRequest: Option<Value>, originalResponse: Option<Value> }
ProxyStatus { running: bool, port: u16, sessionId: Option<String>, requestBreakpoint: bool, responseBreakpoint: bool, caCertPath: String }
PendingExchange { id: String (breakpoint id), exchangeId, stage: String (request/response), method, url, status: Option<u16>, headers: Vec<Header>, body: String, bodyBase64: bool, createdAt: i64 }
EditMessage { action: String (continue/abort), method: Option<String>, url: Option<String>, status: Option<u16>, headers: Option<Vec<Header>>, body: Option<String>, bodyBase64: Option<bool> }

Bodies are persisted; use binary-safe base64 when non-UTF8. The per-body capture limit is 16 MiB; oversized bodies fail explicitly and are not presented as successful complete captures. Proxy binds localhost. Breakpoints must expire and never deadlock shutdown. Replay is a separate outbound request. Scoped MCP reads redact credentials by default.

Traffic rules additionally support `action: {type:"pause",stage:"request"|"response"|"both"}`.
Original request matching is frozen for the transfer. After automatic stage
actions, all matching manual pause selectors coalesce with the global breakpoint
into one pending message per stage. Pause rule evidence is recorded only for a
stage actually reached; direct replay skips pauses and their evidence. Manual
response edits require a final 200–599 status and request edits cannot switch to
CONNECT. Invalid edits leave the pending message available for correction.

## Desktop commands

`bootstrap`, `list_sessions`, `create_session`, `list_exchanges`, `get_exchange`, `analysis`, `export_har`, `import_har`, `export_session`, `import_session`, `start_proxy`, `stop_proxy`, `proxy_status`, `set_breakpoints`, `pending`, `resolve_breakpoint`, `replay`, `compare_sessions`, `list_devices`, `list_apps`, `start_device`, `stop_device`, `device_status`, `set_mcp_scope`, `generate_demo`, `save_export`.

Frontend bridge exposes `api.<command>(args)` using Tauri invoke. In browser mode errors clearly explain that native operations require the desktop app. Demo must be explicitly selected and generated by actual local requests through the proxy, not hardcoded fake capture.

Bootstrap result: `{ sessions, proxy, dataDir, version, deviceStatus, mcpConfig, mcpStatus }`. `mcpConfig` is generated client JSON text; `mcpStatus` contains the in-memory shared session IDs, write permission and local endpoint.
Command arguments use camelCase keys. create_session `{ name, source }`; list_exchanges `{ sessionId, query?, limit?, offset? }`; get_exchange `{ id }`; analysis/export_har/export_session `{ sessionId }`; imports `{ content: String, name?: String }`; start_proxy `{ sessionId, port }`; set_breakpoints `{ request, response }`; resolve_breakpoint `{ id, edit }`; replay `{ id, edit? }`; compare_sessions `{ left, right }`; list_apps `{ serial }`; start_device `{ serial, package, mode: "proxy"|"frida", profile?: String[] }`; generate_demo `{ sessionId }`.

Device { serial, model, state, rooted: bool }
App { package, name, running: bool }
DeviceStatus { running, serial: Option<String>, package: Option<String>, mode: Option<String>, message: String, logs: Vec<String> }

## Scope device API (scope_device)

`DeviceManager::new(runtime_dir: PathBuf) -> DeviceManager` (Clone)
`manager.list_devices() -> async Result<Vec<Device>>`
`manager.list_apps(serial: &str) -> async Result<Vec<App>>`
`manager.start(serial: String, package: String, mode: String, proxy_port: u16, ca_cert: PathBuf, profile: Vec<String>) -> async Result<DeviceStatus>`
`manager.stop() -> async Result<DeviceStatus>`
`manager.status() -> DeviceStatus`

ADB discovery uses env ANDROID_HOME/ANDROID_SDK_ROOT, common SDK locations and PATH. Never claim per-app attribution in global proxy mode. The desktop must show that mode is device-wide. Frida JS runs in a separate worker; do not port vendored unsafe hooks manually into Rust. Preserve upstream license notices. No device changes until Start interception.

Native dispatch: `invoke("scope_command", {command, args})`. `save_export` `{sessionId,format:"har"|"scope"}` opens a native save dialog and returns `{saved,path?}`; cancelled dialogs return saved=false.
