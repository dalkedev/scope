# Scope 1.2.1: macOS build maintenance

Scope 1.2.1 moves macOS CI and release packaging to GitHub's supported macOS 15
arm64 runner after the previous macOS 14 runner stopped accepting jobs. This is
a build-host change. Application deployment-target settings, capture, replay,
archive formats, traffic filters and HAR comparison are unchanged.

The release documentation now distinguishes the published 1.2.0 release from
maintenance preparation. Scope 1.2.0 already includes the reusable offline HAR
comparison Action, refreshed project identity and desktop icons.

## Downloads and verification

Packages target macOS arm64, Windows x64 and Linux x64, with source ZIP,
per-platform build manifests and SHA-256 checksums. Verify downloads against
`SHA256SUMS.txt` and check the source commit in the build manifest. Optional native
Frida binaries remain excluded from public packages and can be installed
separately with the included setup helper.

[The verification record](https://github.com/dalkedev/scope/blob/v1.2.1/docs/VERIFICATION.md)
keeps hosted build checks separate from interactive runtime observations.
This maintenance release does not add new interactive desktop/device coverage.
The macOS package is ad-hoc signed and is not Apple-notarized. Windows/Linux
interactive behavior remains experimental; Intel macOS is unverified.
[Existing dependency findings](https://github.com/dalkedev/scope/blob/v1.2.1/docs/DEPENDENCIES.md)
remain documented.

Back up important captures before upgrading. Bodies remain buffered up to 16 MiB
each. WebSocket frames, trailers, HTTP/3 and large-session streaming are unchanged.

**AGPL-3.0-or-later.** Third-party notices remain included.
