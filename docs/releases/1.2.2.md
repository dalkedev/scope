# Scope 1.2.2: GLib backport maintenance

Scope 1.2.2 backports the upstream `VariantStrIter` soundness fix into GLib 0.18.5,
which Tauri's Linux GTK/WebKit dependency family requires. The real GLib version
and original license remain intact. The source archive includes the pristine
crate, exact upstream patch and provenance; only the two-line upstream fix
changes vendored source.

Checks and release builds verify every vendored file and Cargo's locked package
selection, then run optimized Linux iterator regressions. The verifier preserves
exact bytes under Windows Git settings and reads Cargo metadata explicitly as
UTF-8. Dependency notices preserve gtk-rs authorship and link the original crate
and Scope's modified source. Individually reviewed CodeQL flows and concrete
conversion/ownership tests are documented without disabling code scanning.

Capture, replay, archive formats and the offline HAR comparison CLI/Action are
unchanged. No unrelated dependency version migration is included.

## Downloads and verification

Packages target macOS arm64, Windows x64 and Linux x64, with source ZIP,
per-platform build manifests and SHA-256 checksums. Verify downloads against
`SHA256SUMS.txt` and check the source commit in the build manifest. Optional
native Frida binaries remain excluded and can be installed separately with the
included setup helper.

[Backport provenance](https://github.com/dalkedev/scope/blob/v1.2.2/vendor/glib-provenance/README.md)
records the precise source inputs and removal conditions. Cargo-audit does not
match local path packages against registry advisories; its missing GLib warning
is not evidence of the fix. Other version-based scanners may still report
RUSTSEC-2024-0429 because the honest version remains 0.18.5.
[Dependency findings](https://github.com/dalkedev/scope/blob/v1.2.2/docs/DEPENDENCIES.md)
remain documented.

[Recorded verification](https://github.com/dalkedev/scope/blob/v1.2.2/docs/VERIFICATION.md)
distinguishes build/headless evidence from interactive observations. Issue #11
remains open for GTK/dialog acceptance. This release adds no interactive
desktop/device coverage: Windows/Linux interactive behavior remains
experimental, Intel macOS is unverified, and the macOS package is ad-hoc signed
without Apple notarization.

Back up important captures before upgrading. Bodies remain buffered up to 16 MiB
each. WebSocket frames, trailers, HTTP/3 and large-session streaming are unchanged.

**AGPL-3.0-or-later.** Third-party notices remain included.
