existing header banner, the navigation links and a smaller mascot sign below
the introduction. The sign keeps the Snurpo identity and matches the website
sign artwork used across the author's projects.

This is a branding and documentation update only. It does not change the app
version, runtime, desktop icons or release artifacts, and creates no version tag
or release. The `release/1.5.0-website` branch uses the repository's existing
proposal workflow to request normal maintainer review.
