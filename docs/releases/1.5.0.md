# Snurpo 1.5.0: take the request to your terminal

The request inspector now offers **Copy as cURL**. Open a preview of the captured
request, review it, then copy a complete command into a POSIX terminal. This
closes the gap between inspecting a request and reproducing it outside Snurpo.

## Copy as cURL

- Preserve the effective method, URL, repeated headers and text or binary body.
- Review a readable command before copying. Captured credentials remain visible;
  this is a debugging export, not a sanitized sharing copy.
- Get explicit clipboard success or select the command manually if access fails.
- Previewing and copying never execute the command or send traffic.

Output targets **sh, bash and zsh**, including a compatible shell on Windows.
PowerShell and cmd.exe syntax are not generated. Running the command uses your
terminal's network settings; Snurpo rules and breakpoints are not applied.
Transport headers are normalized, TLS verification stays enabled, and redirects
and retries are not added. Malformed, oversized and HEAD-with-body requests show
an explanation instead of a partial command. Commands stay below 128 KiB.
[Full behavior and limits](https://github.com/dalkedev/snurpo/blob/v1.5.0/docs/GETTING_STARTED.md#copy-a-request-to-your-terminal).

## Downloads and compatibility

- **macOS Apple Silicon:** `Snurpo-v1.5.0-macOS-arm64.zip` contains `Snurpo.app`.
- **Windows x64:** `Snurpo-v1.5.0-Windows-x64-setup.exe`.
- **Linux x64:** AppImage and Debian package.
- **Source:** `Snurpo-v1.5.0-source.zip`; verify downloads with `SHA256SUMS.txt`.

Saved sessions, CA trust, archive formats and MCP identifiers remain compatible.
The separate HAR CLI remains version 0.1.0. The installed app needs no Node
runtime; source tooling uses Node 26.13.1 LTS.

The macOS package is ad-hoc signed, not Apple-notarized. Windows/Linux interactive
installers, upgrades and device behavior remain experimental; Intel macOS is
unverified. Optional native Frida binaries remain excluded. This release does
not expand Android, streaming or WebSocket support. See the
[verification record](https://github.com/dalkedev/snurpo/blob/v1.5.0/docs/VERIFICATION.md)
and [dependency notes](https://github.com/dalkedev/snurpo/blob/v1.5.0/docs/DEPENDENCIES.md).

The existing native gallery records Snurpo 1.4.2. Historical releases and their
checksums are unchanged.
