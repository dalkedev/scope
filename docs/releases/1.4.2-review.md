# Release Snurpo 1.4.2 with clean native screenshots

The application currently on `main` uses Snurpo branding but still reports 1.4.1;
public downloads are Scope 1.4.1. This proposal bumps the desktop application,
npm metadata, Rust workspace packages and Tauri bundle to **1.4.2** so the next
tag can publish distinct Snurpo packages. The independently versioned HAR tool
and compatibility identifiers remain unchanged.

Remove the redundant `local` badge beside the logo. Refresh the native macOS
workflow gallery in fullscreen to exclude the system capture/title strip, with
the pointer outside the captured window. The screenshots show real persisted
localhost exchanges, saved rules and replay output; they are not image-generated
or retouched.

Current installation, status and migration documentation describes Snurpo
1.4.2. The reviewed public release body is `docs/releases/1.4.2.md`. Historical
Scope releases, assets, verification records and checksums are preserved.

## Validation and publication

- UI tests, production frontend build, release/license checks and version
  consistency checks pass locally.
- The local 1.4.2 macOS package passes signature/resource and engine/MCP smoke
  checks; native screenshot review uses the same packaged frontend.
- Required Windows, Ubuntu and macOS CI must pass on this exact proposal before
  merge. The tagged draft workflow builds fresh downloadable artifacts and
  checksums from the merged commit before public release.
- macOS remains ad-hoc signed, not Apple-notarized. Windows/Linux interactive
  installers and upgrades remain experimental; this release does not broaden
  Android coverage.

After normal review and artifact checks, publish the verified draft as stable
Snurpo 1.4.2. Branch protection and packaging gates remain unchanged.
