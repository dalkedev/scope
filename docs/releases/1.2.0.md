# Scope 1.2.0: Offline comparisons in your workflow

Scope 1.2.0 adds a reusable GitHub Action for the existing offline HAR comparison
CLI, refreshes the project identity and desktop icons, and updates frontend and
build dependencies. Capture, replay, archive formats and existing free features
remain available.

## Compare local HAR captures in CI

The composite Action lives at `.github/actions/har-compare`. Give it baseline and
current HAR files, an optional contract/config and a new output directory. It
uses its own bundled CLI and emits JSON, standalone offline HTML and JUnit XML.
Node 22.22.3+ and Bash are supplied by the caller; Linux is the initial supported
runner. The comparison itself needs no account, model, token or network access.

Outputs distinguish clean (`0`), regression (`1`) and invalid/incomplete (`2`).
The default step fails on either nonzero result. Set `fail-on-result: 'false'`
only when a later gate checks the exact result and rejects missing outputs.
Complete reports remain available for regression results. Existing output
directories are refused so stale reports cannot masquerade as a new result.

The Action defaults to `labels: ids` and never uploads files or posts comments.
Minimized labels do not anonymize traffic patterns. Review derived reports before
sharing; raw captures and configuration should stay in trusted local storage.
Observation alone does not reject an unchanged HTTP 500: use authored status
requirements. Repeated requests pair by encounter order, with the CLI's existing
input bounds and matching limitations.

## Refreshed Scope identity

The new two-path cyan mark appears in the source assets, repository banner and
desktop icon set. The banner is brand artwork; the application gallery remains
real screenshots from its separately recorded capture version. Desktop behavior
and existing interaction colors are unchanged.

GitHub Actions are pinned to updated commits. Lucide React is 0.577.0 and
TypeScript is 5.9.3. Generated dependency notices include the updated Lucide
copyright and Feather-derived MIT text, with hashes of the release lockfiles.

## Packages and verification

Release packaging targets macOS arm64, Windows x64 and Linux x64, with source
ZIP, platform build manifests and SHA-256 checksums. Verify the manifest's source
commit and downloaded files against `SHA256SUMS.txt`. Optional native Frida
binaries are installed separately and remain excluded from public packages.

[The verification record](https://github.com/dalkedev/scope/blob/v1.2.0/docs/VERIFICATION.md)
distinguishes local tests, exact-commit hosted checks and interactive runtime
coverage. Earlier macOS/Android observations do not establish 1.2.0 desktop or
device validation. The macOS package is ad-hoc signed, without Apple notarization.
Windows/Linux interactive behavior remains experimental; Intel macOS is unverified.
[Existing dependency findings](https://github.com/dalkedev/scope/blob/v1.2.0/docs/DEPENDENCIES.md)
remain documented.

Back up important captures before upgrading. Bodies remain buffered up to 16 MiB
each; WebSocket frames, trailers, HTTP/3 and large-session streaming are not added.
