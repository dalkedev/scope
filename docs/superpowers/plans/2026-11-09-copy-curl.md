# Copy as cURL Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Export selected requests to reviewed, explicitly copied POSIX cURL commands.
**Architecture:** Pure request-to-command helper, isolated preview component, inspector entry point.
**Tech Stack:** Existing React/TypeScript/Vitest; no dependencies.
**Spec:** docs/superpowers/specs/2026-11-09-copy-curl-design.md

## Global Constraints

- Preserve the current released version, captured data and existing replay behavior; review any release bump separately.
- Command UTF-8 length at most 128 KiB; only HTTP(S); no automatic execution.
- POSIX sh/bash/zsh output, explicitly labeled; no Windows-shell claim.

## Review Focus

- Imported malformed records fail without exposing a runnable partial command.
- Untrusted quotes, substitutions, newlines and @ prefixes remain literal bytes.
- Empty and repeated headers retain meaning without stale framing headers.
- Binary/NUL and Unicode bodies survive actual terminal execution.
- Clipboard rejection and exchange switching never report stale success.
