# Collected application dependency notices

Open [index.html](index.html) for the human-readable license collection. `rust.json` and `frontend.json` record package versions, source locations and original license text with the corresponding lockfile SHA-256.

Generated by `scripts/licenses.mjs` using cargo-about 0.9.3 and installed npm runtime packages. Rust build/dev dependencies and npm development tools are excluded. The Rust report includes platform-specific packages that may be absent from an individual artifact. Original third-party terms apply; Snurpo's AGPL license does not replace them.

Workspace crates are attributed to Snurpo. Their `scope-*` package identifiers remain compatible with existing build commands. The vendored GLib 0.18.5 entry preserves its gtk-rs upstream repository and links the original published crate, Snurpo's modified source, and the backport provenance. Its original MIT license remains included; the HTML collection also links the backport provenance. Other path dependencies require a declared public repository.

Regeneration instructions and current dependency findings are in [docs/DEPENDENCIES.md](../../docs/DEPENDENCIES.md). Vendored hooks and optional Frida runtimes are covered by [THIRD_PARTY_NOTICES.md](../../THIRD_PARTY_NOTICES.md).

The notice generator compares existing local manifest paths canonically, so
filesystem aliases such as macOS `/var` and `/private/var` retain the same GLib
backport attribution. Missing manifests cannot claim the vendored backport path.
`node --test scripts/licenses.test.mjs` exercises real fixture manifests and a
directory alias (a junction on Windows), with test-only Cargo discovery data.
The generator itself runs in a child Node process on all three CI platforms;
no Unix executable wrapper or Windows shell wrapper is required.
